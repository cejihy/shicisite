# 夜访 · 画卷

一条竖着的时间轴（鱼骨），二十四位诗人散在上面；点一个人，挂出他的诗词；再点一首，进那一夜。

## 上 GitHub Pages

1. 在 GitHub 新建一个仓库（Public）。
2. 把这个文件夹里的**全部文件**传上去（网页上拖拽也行）。
3. 仓库 → Settings → Pages → Source 选 `Deploy from a branch`，
   Branch 选 `main`，目录选 `/ (root)`，保存。
4. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`。

## 手机上装到主屏

Safari 打开上面的地址 → 分享 → **添加到主屏幕**。
之后点图标就是全屏、断网也能开（首次要联网装一次）。

## 文件

- `index.html` —— 全部内容（纸的纹理、人物、台词都在里面，无外链）
- `manifest.webmanifest` —— 名字与图标
- `sw.js` —— 离线缓存
- `icon-180.png` / `icon-512.png` / `icon-32.png` —— 图标

## 操作

- 鼠标：滚轮过时间，按住拖动也行
- 手机：单指上下拖，松手会滑一段
- 点竖牌 → 诗墙；点横批 → 读那一夜；Esc / 左上角退回
